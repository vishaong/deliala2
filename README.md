# 미출고 알람 서비스

델리버리 트래커 API를 사용한 배송 상태 추적 서비스입니다.

## 기능

- **설정 페이지**: 델리버리 트래커 크레덴셜 정보 입력 및 저장
- **메인 페이지**: 
  - 택배사 선택 (롯데택배, 쿠팡 로지스틱스 서비스, 로젠택배)
  - 송장번호 입력 및 등록
  - 등록된 송장 목록 표시 (송장번호, 마지막 배송 상태)
- **상세 페이지**: 송장 클릭 시 배송 상태 상세 정보 조회

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```

## 사용 방법

1. 설정 페이지에서 델리버리 트래커에서 발급받은 Client ID와 Client Secret을 입력합니다.
2. 메인 페이지에서 택배사를 선택하고 송장번호를 입력하여 등록합니다.
3. 등록된 송장 패널을 클릭하면 상세 페이지로 이동하여 배송 상태를 확인할 수 있습니다.

## 기술 스택

- React 18
- TypeScript
- Vite
- React Router
- 델리버리 트래커 API

## 참고

- 크레덴셜 정보는 브라우저의 로컬 스토리지에 저장됩니다.
- 송장 정보도 로컬 스토리지에 저장됩니다.
- 상세 페이지에서만 배송 상태를 조회하도록 설계되어 있습니다 (Polling 최소화).
