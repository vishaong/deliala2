# 미출고 알람 서비스

델리버리 트래커 API를 사용한 배송 상태 추적 및 슬랙 알림 서비스입니다.

## 기능

### 기본 기능
- **설정 페이지**: 델리버리 트래커 크레덴셜 정보 입력 및 저장
- **메인 페이지**: 
  - 택배사 선택 (롯데택배, 쿠팡 로지스틱스 서비스, 로젠택배)
  - 송장번호 입력 및 등록
  - 등록된 송장 목록 표시 (송장번호, 마지막 배송 상태)
- **상세 페이지**: 송장 클릭 시 배송 상태 상세 정보 조회

### 슬랙 알림 기능
- **슬랙 웹후크 연동**: 슬랙 웹후크 URL을 설정하여 알림을 받을 수 있습니다
- **모니터링 주기 설정**: 배송 상태를 조회하는 주기를 설정할 수 있습니다 (5분~24시간)
- **알림 옵션**:
  - **출고지연 시 알림** (기본값: ON): 등록 후 48시간 이내 미출고 시 알림
  - **출고 시 알림** (기본값: OFF): 배송이 시작되면 알림
  - **배송 완료 시 알림** (기본값: OFF): 배송이 완료되면 알림
  - **배송 예외 시 알림** (기본값: OFF): 반송, 지연 등의 예외 발생 시 알림

## 설치 및 실행


## 사용 방법

1. **설정 페이지**에서 다음을 설정합니다:
   - 델리버리 트래커에서 발급받은 Client ID와 Client Secret
   - 슬랙 웹후크 URL (선택사항)
   - 모니터링 주기 (기본값: 30분)
   - 알림 옵션 (출고지연 알림은 기본적으로 활성화됨)

2. **메인 페이지**에서 택배사를 선택하고 송장번호를 입력하여 등록합니다.

3. 등록된 송장은 설정된 주기에 따라 자동으로 모니터링되며, 조건에 맞는 경우 슬랙으로 알림이 전송됩니다.

4. 등록된 송장 패널을 클릭하면 상세 페이지로 이동하여 배송 상태를 확인할 수 있습니다.

## 슬랙 웹후크 URL 설정 방법

1. 슬랙 워크스페이스에서 [Incoming Webhooks](https://api.slack.com/messaging/webhooks) 앱을 추가합니다.
2. 웹후크 URL을 생성합니다.
3. 설정 페이지의 "슬랙 웹후크 URL" 필드에 생성된 URL을 입력합니다.
4. "테스트 전송" 버튼을 클릭하여 연결을 확인합니다.

## CORS 문제 해결

이 애플리케이션은 브라우저 환경에서도 슬랙 메시지 전송이 작동하도록 설계되었습니다:

- **개발 환경**: Vite 프록시를 통해 슬랙 웹후크를 호출합니다.
- **프로덕션 환경**: 
  1. 먼저 슬랙 웹후크 URL에 직접 호출을 시도합니다 (슬랙 웹후크는 일반적으로 CORS를 허용합니다).
  2. CORS 오류가 발생하는 경우 `no-cors` 모드를 사용하여 요청을 전송합니다 (응답 확인은 불가하지만 요청은 전송됩니다).

대부분의 경우 슬랙 웹후크는 CORS를 허용하므로 직접 호출이 작동합니다. 만약 문제가 발생한다면 자동으로 대체 방법을 시도합니다.

## 참고

- 크레덴셜 정보와 설정은 브라우저의 로컬 스토리지에 저장됩니다.
- 송장 정보도 로컬 스토리지에 저장됩니다.
- 모니터링은 백그라운드에서 주기적으로 실행되며, 설정된 주기에 따라 배송 상태를 조회합니다.
- 출고지연 알림은 송장 등록 후 48시간이 지났지만 아직 출고되지 않은 경우에만 전송됩니다 (중복 알림 방지).
- 델리버리 트래커의 웹후크 API는 서버 환경에서 콜백을 받을 수 있을 때 사용할 수 있습니다. 현재는 브라우저 환경이므로 주기적 모니터링 방식을 사용합니다.

## 최근 업데이트 (2025-11-26)

### 버그 수정: 미출고 알림 오류 해결
- **문제**: 송장 등록 후 아직 출고되지 않아 배송 정보가 없는 경우(API 오류 발생), 48시간이 지나도 "출고 지연" 알림이 전송되지 않는 문제가 있었습니다.
- **해결**: API 오류가 발생하더라도 등록 후 48시간이 지났다면 "정보 없음 (API 오류)" 상태로 간주하여 출고 지연 알림을 전송하도록 수정했습니다.

### 리팩토링
- 모니터링 로직(`monitoring.ts`)을 개선하여 알림 전송 코드를 중복 제거하고 가독성을 높였습니다.
- 슬랙 알림 전송 시 개발 환경과 프로덕션 환경의 호환성을 개선했습니다.
